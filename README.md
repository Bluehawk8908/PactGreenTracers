# Customizable Tracers 
A GHPC mod that allows the user to differentiate NATO and Warsaw Pact small-calibre tracers by colour, and to customize the RGB values of both through the MelonLoader config file. By default, the mod assigns red to NATO and green to Pact forces.  
The frequency of tracers in the belt can also be changed, the default value of 5 signifies one tracer in every 5 rounds. Assigning 10, for example, will make tracers half as common, but a value of 0 will eliminate tracers altogether.

Requires MelonLoader 0.6.1. Install the DLL into your /mods/ folder. Compatible with Pact Increased Lethality.
