# Pact Green Tracers  
A GHPC mod that changes the colour of Warsaw Pact machine-gun tracers, 7.62x54R and 12.7x108mm, from red to green.  

Requires MelonLoader 0.6.1. Install the DLL into your /mods/ folder. Compatible with Pact Increase Lethality.
